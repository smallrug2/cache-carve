## What it does
Carves JPEG and PNG images out of opaque browser/app cache blobs by signature scanning.


## Requirements
Python 3.8+ only - stdlib only (uses Pillow for verification ONLY if already installed).


## How to run
    python cache_carve.py --help
    python cache_carve.py --indir ./cache --outdir ./carved


## Platform
Windows + Linux + Mac: yes.
